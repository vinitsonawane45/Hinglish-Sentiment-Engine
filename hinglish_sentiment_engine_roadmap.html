Research & gap analysis
Weeks 1–2
The real gap: Most Hinglish models handle Roman-script only. Almost none handle mixed Roman+Devanagari in the same sentence, sarcasm in code-mixed text, or aspect-level sentiment — your differentiation opportunities.
Key prior work to read
SemEval-2020 Task 9 paper (Patwa et al.) · L3Cube-HingBERT paper (arXiv 2204.08398) · COMI-LINGUA 2025 dataset paper
Model landscape
mBERT, HingBERT, HingMBERT, HingRoBERTa all exist — but none are fine-tuned specifically for sentiment and publicly served as an API/demo
Your differentiators
Sarcasm-aware labels · Aspect-level sentiment · Devanagari+Roman mixed input · Open Streamlit demo anyone can use

Data collection & curation
Weeks 2–5
SemEval-2020 Hinglish
20K tweets, word-level language tags + sentence sentiment labels. Best starting dataset. Download from CodaLab.
L3Cube HingCorpus
52M sentences from Twitter. Use HingBERT-LID to filter high code-mix sentences for your training augmentation.
MUTANT dataset
67K articles with Hinglish multi-sentence context. Useful for longer-form social media post experiments.
Collect fresh data
Scrape recent Instagram/YouTube comments using Playwright or snscrape. Aim for 5–10K new samples across IPL, Bollywood, politics domains.
Annotation pipeline
Label with: Positive / Negative / Neutral + optional Sarcastic flag. Use Label Studio (free, self-hosted). 3 annotators per sample, majority vote.
Preprocessing
Normalize @mentions, URLs, emoji → text description. Handle Roman↔Devanagari normalization using IndicNLP library.

Model fine-tuning
Weeks 5–9
Baseline: mBERT
Fine-tune google-bert/bert-base-multilingual-cased on SemEval data. Target: replicate ~75% F1 as baseline.
Step up: HingMBERT
Use l3cube-pune/hing-mbert — already pre-trained on 52M Hinglish tokens. Fine-tune for sentiment on top. Likely your best model.
Experiment: XLM-RoBERTa
facebook/xlm-roberta-base — strong multilingual baseline. Compare vs HingMBERT on your test split.
Advanced: MuRIL
google/muril-base-cased — trained on Indian languages including transliterated text. Try for mixed-script inputs.
Training config
LR: 2e-5 · Batch: 16 · Epochs: 3–5 · Warmup: 10% · Dropout: 0.1 · Use Trainer API from HuggingFace transformers
Loss & metrics
CrossEntropyLoss with class weights (class imbalance is common). Report macro-F1, per-class F1, confusion matrix.
Free GPU
Google Colab Pro (~₹1000/mo) or Kaggle (30 hr/week free T4). Use bfloat16 mixed precision to fit in 16GB VRAM.
